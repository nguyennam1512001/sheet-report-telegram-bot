# Sheet Export to Telegram (Personal Account)

This project exports selected Google Sheets ranges to PDF, converts each page to a trimmed PNG, and sends the images to a Telegram group using a **personal Telegram account** (MTProto via [teleproto](https://www.npmjs.com/package/teleproto)).

## GitHub Actions secrets

Keep the existing Google Sheets settings:

- `GOOGLE_SERVICE_ACCOUNT_JSON`
- `SPREADSHEET_ID`
- `SHEET_NAMES` (optional; defaults to `Ladi,Mydu`)
- `START_COL` (optional; defaults to `F`)
- `END_COL` (optional; defaults to `AD`)
- `MAX_ROWS_PER_FILE` (optional; defaults to `40`)

Telegram settings:

- `TELEGRAM_API_ID` — from [my.telegram.org/apps](https://my.telegram.org/apps)
- `TELEGRAM_API_HASH` — from the same Telegram application page
- `TELEGRAM_SESSION` — session string generated by the one-time login below
- `TELEGRAM_CHAT_ID` — existing numeric group ID (for example `-100...`) or a public group username (for example `@groupname`)

The personal account must already be a member of the destination group and have permission to send photos. The group ID is not a bot token and should remain the same unless the destination group changes.

## One-time Telegram login

1. Install Node.js 20 or newer on your computer.
2. Clone this repository and run `npm install` in its folder.
3. Open [my.telegram.org/apps](https://my.telegram.org/apps), sign in with the Telegram account that will post to the group, and create an application if you have not already. Copy its API ID and API Hash.
4. Run `npm run login:telegram`.
5. Enter the API ID, API Hash, phone number, and the login code Telegram sends. If two-step verification is enabled, enter its password when prompted.
6. Copy the generated session string and save it in GitHub repository **Settings → Secrets and variables → Actions → New repository secret**, named `TELEGRAM_SESSION`.
7. Add `TELEGRAM_API_ID` and `TELEGRAM_API_HASH` as repository secrets too.

**Security:** The session string grants access to the Telegram account. Treat it like a password. Never paste it into chat, commit it to the repository, or expose it in workflow logs. If it leaks, terminate the corresponding Telegram session from an official Telegram app and generate a new one.

## Run

Open **Actions → Export Sheets to Telegram (manual) → Run workflow**. The workflow uses the saved session and does not ask for a login code on each run.

Images are sent in batches of up to 10 per Telegram album. The sheet caption is attached to the first image batch only. Use the account conservatively: repeated high-volume or spam-like automation can trigger Telegram limits or account restrictions.
